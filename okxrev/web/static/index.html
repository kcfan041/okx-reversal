控制

暫停是怎麼運作的？
  • 暫停收集：建立 data/PAUSE，排程仍每 5 分鐘觸發但立即結束（幾乎不耗資源）；紙上交易、過熱分數更新、提醒、實驗室規則偵測也一起停。
  • 恢復：移除旗標。下一次同步會補回 K 線、主動買賣量、溢價、資金費率等可回補的資料（停很久時會分幾輪補完）；多空比（約 1 天）、爆倉（每幣最新約 100 筆）、OI 5 分鐘（幾小時）超過保留期的部分無法補回。
  • 暫停中按「立即執行同步」或「立即跑一輪」紙上交易會先確認。網頁的即時查詢（持倉、盯盤、AI 即時資料）不受影響。
  • 命令列：uv run python -m okxrev.collect --pause | --resume | --status
  • 不會修改 Windows 工作排程本身（需要系統管理員權限）。若排程被手動停用，這裡會提示。
